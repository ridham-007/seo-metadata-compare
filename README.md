# SEO Metadata Compare

Install dependencies:

```sh
npm install
```

Run locally:

```sh
npm run dev
```

Run the checks and build:

```sh
npm run lint
npm test
npm run build
```

GitHub Actions runs the checks on pushes to `test-pipeline`, then deploys successful builds to GitHub Pages. It can also be started manually.
